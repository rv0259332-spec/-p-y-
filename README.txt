# 📟 ОСТАВЛЕННЫЙ / THE ABANDONED (Project 1999)

> **"Игра, созданная искусственным интеллектом, про искусственный интеллект."**

Добро пожаловать в ретро-текстовый квест в жанре психологического кибер-хоррора. Проект выполнен в стилистике старых терминалов 1999–2000 годов.

## 📁 История версий в репозитории:
* ⚠️ **GAME.py** — Самая первая, ранняя бета-версия (черновик кода).
* 🧱 **1.py, 2.py, 3.py** — Промежуточные версии и тесты механик.
* 🏆 **4.py** — 🔥 ФИНАЛЬНЫЙ РЕЛИЗ ИГРЫ! Самая полная и стабильная версия.

## 🚀 Как запустить финальную версию:
1. Скачайте файл **4.py**.
2. Откройте его через IDLE Python или запустите прямо в Командной строке (CMD).
3. Нажмите клавишу **F5** на ноутбуке для старта.
4. Используйте **Пробел** для быстрой перемотки старого текста!
